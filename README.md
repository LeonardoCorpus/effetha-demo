# Effetha: Landing para agencia de marketing y relaciones públicas

<img width="1395" height="895" alt="effeta" src="https://github.com/user-attachments/assets/8f026676-6fb9-458a-9327-bbd60c134629" />

Landing page para una agencia enfocada en marca personal, tecnología y relaciones públicas. Diseñada en Figma y desarrollada en WordPress con Elementor.

🔗 **Demo en vivo:** https://leonardocorpus.github.io/effetha-demo/

## Qué hice!

- Llevé el diseño de Figma a WordPress con Elementor Pro
- CSS personalizado para tarjetas flotantes, botones y estilos de la portada
- Diseño responsive (escritorio, tablet y móvil)
- Exporté el sitio a HTML estático con Simply Static para publicarlo en GitHub Pages

## Tecnologías
WordPress · Elementor · CSS3 · Figma · Local · GitHub Pages

## Nota
Este repositorio contiene la versión estática de la demo. Los formularios y funciones dinámicas de WordPress no están activos en esta versión.
